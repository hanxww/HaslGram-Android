# HaslGram — официальный сайт проекта (статический лендинг)

Готовый адаптивный сайт на русском языке, без сборщика, внешних библиотек и аналитики. Содержит главную страницу, возможности, экосистему Hasl Stars / Premium / подарков / +888, план разработки, FAQ, раздел тестовых Android-сборок.

## Запуск

Откройте `index.html` в браузере. Для локального веб-сервера:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000/`.

## Публикация

Скопируйте содержимое этой папки в корень статического хостинга (GitHub Pages, Cloudflare Pages, Netlify или свой сервер). При публикации на GitHub Pages из подкаталога `.github/workflows/site-pages.yml` может автоматически развернуть сайт **после включения Pages в настройках репозитория** (Settings → Pages → Source → GitHub Actions).

**Адрес сайта пока не установлен.** Файл `CNAME` намеренно отсутствует. Если у вас есть домен, сначала подтвердите, что вы им управляете, настройте DNS, затем создайте `CNAME` с вашим доменом.

## Редактирование

- `index.html`: тексты, разделы, ссылки.
- `styles.css`: оформление, адаптивность.
- `app.js`: мобильная навигация и год в подвале.
- `assets/haslgram-icon.webp`: иконка проекта, уже согласованная ранее.
- `assets/og-cover.jpg`: обложка для социальных сетей. После публикации с постоянным URL рекомендуется заменить относительный `og:image` абсолютным адресом.

## Статусы

Сайт намеренно не утверждает, что сервер начисляет 2000 Stars, продаёт подарки или выдаёт номера +888 прямо сейчас. Всё это отмечено как **в разработке** или **в планах**. Рабочая тестовая сборка Android доступна через GitHub Actions, но может требовать входа в GitHub для скачивания.

HaslGram — отдельный проект, не является официальным приложением Telegram. Внутренние Hasl Stars не являются Telegram Stars.
