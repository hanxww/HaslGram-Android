ЕСТЬ ВОПРОСЫ?

Всё по делу.

Можно ли уже пользоваться HaslGram?+

Доступны тестовые APK для Android. Мы ещё проверяем вход, соединение, чаты и оформление, поэтому пока не рекомендуем использовать приложение для важных переписок.

Нужно ли выбирать сервер при входе?+

В обновлённой версии клиента убираем экран выбора сервера и кнопку Join. Приложение должно автоматически подключаться к сети HaslGram перед регистрацией. Изменение проходит тестирование.

Когда появятся Hasl Stars и подарки?+

Система находится в разработке. Планируется стартовый бонус 2000 Hasl Stars, обычная покупка подарков и улучшение по отдельному действию пользователя. Реальные покупки станут доступны только после внедрения серверной экономики.

HaslGram связан с Telegram?+

HaslGram — независимый проект на базе открытого исходного кода Telegram-подобного клиента. Мы развиваем собственную сеть; это не официальное приложение Telegram, а Stars и подарки двух сервисов не взаимозаменяемы.
